GLOBAL RULES (every embed obeys these)
────────────────────────────────────────
• Color accents (Discord) — set per embed variant:
    ACTIVE   #57F287 (green)   warning #FEE75C (yellow)
    INACTIVE #ED4245 (red)     neutral #2B2D31 (dark)
    info     #5865F2 (blurple)  gold    #FFD700 (leader #1)
• Every embed: title starts with an emoji, ends with a footer
  "Peace✘ VC · <relative timestamp>".
• HMS always formatted via formatHMS(); numbers get thousands separator.
• Members always <@id> mentions (never raw IDs) — uncached members
  are fetched via members.fetch() before display.
• Every command defers then edits → no freezes.
• Buttons customId: vc:<area>:<action>:<ctx>
  (e.g. vc:stats:prev:<gid>:<uid>, vc:report:page:2)

FIX #9 · formatHours() — THE ONE TRUE HOURS FORMATTER (applies
EVERYWHERE: hero block, stats strip, Sunday report, /vctask columns)
────────────────────────────────────────────────────────────────────
  formatHours(seconds):
    - hours > 0 && minutes > 0  → "412h 30m"
    - hours > 0 && minutes == 0 → "412h"
    - hours == 0 && minutes > 0 → "30m"
    - all zero                  → "—"
  Tests that must pass:
    - formatHours(1485000) === '412h 30m'
    - formatHours(1483200) === '412h'
    - formatHours(1800)    === '30m'
    - formatHours(0)       === '—'
  (Replaces every ad-hoc "412h" / "412h 30m" mix seen in v1.)

FIX #7 · chartBar / progressBar — MOBILE-SAFE WIDTHS
────────────────────────────────────────────────────────────────────
  chartBar(width) and progressBar(p) NEVER render a bar longer than
  10 characters, no matter how big the value (clamped). Every embed
  that renders a bar/chart appends a small note row:
      📱 Mobile-safe: bars capped at 10 chars
  Chart rows use a monospace code block; bar fill ▰ done / ▱ todo.
  Example (capped, 10-char max):
      Sun ██████████ 4h 25m 36s    ← 10 chars, NOT more
      Sat █████████  3h 07m 36s
  TEST: "chart bars never exceed 10 chars regardless of value".


PROGRESS PRIMITIVE (used everywhere)
────────────────────────────────────────
progressBar(p, len) → ▰ done / ▱ todo, e.g. 9h30m / 10h:

    9h30m / 10h  ▰▰▰▰▰▰▰▰▱▱▱▱   95%     ...

    triggers:
      100% → active color
      >= 95% → caution (any)
      < 95% → inactive color
      + "⚠ 30m left" inline hint when within reach (>= 85%)
