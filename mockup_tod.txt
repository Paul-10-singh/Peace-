GLOBAL RULES (every embed obeys these)
────────────────────────────────────────────────────────────────────────
• Color accents (Discord) — set per embed variant:
    ACTIVE   #57F287 (green)   warning #FEE75C (yellow)
    INACTIVE #ED4245 (red)     neutral #2B2D31 (dark)
    info     #5865F2 (blurple)  gold    #FFD700 (leader #1)
• Every embed: title starts with an emoji, ends with a footer
  "Peace✘ Truth or Dare · <relative timestamp>".
• Members always <@id> mentions (never raw IDs) — uncached members
  are fetched via members.fetch() before display.
• Every command defers then edits → no freezes.
• Buttons customId: tod:<area>:<action>:<ctx>
  (e.g. tod:panel:start, tod:round:truth:<gid>:<sid>:<uid>)
• SelectMenus customId: tod:<area>:<select>:<ctx>
• Modals customId: tod:<area>:modal:<ctx>

─ EMOJI RULES (identical policy to VC module) ────────────────────────────
• Never hardcode emojis in commands — always import from emojis.js.
• Custom emoji IDs come from a central src/utils/shared/emojis.js
  registry (reuse VC's stored custom set where semantics overlap —
  correct/wrong/time/status — via the shared E object). No invented
  IDs, no new uploads.
• React/UI build uses the bot's stored customs whenever a default
  glyph has an equivalent; pure-Unicode defaults stay spelled out so
  review sees the exact glyph.

  │ Buttons: [✅ Done] [⏭️ Skip] [❌ Refuse]                 │

  ── STATES ─────────────────────────────────────────────────
  [✅ Done] → bot posts: "✅ @UserB completed it! Round n → 
             next player" (public in channel, footer stamp)
  [⏭️ Skip] → bot posts: "⏭️ @UserB skipped. Round n → next 
             player"
  [❌ Refuse] → strike #1/3: "❌ @UserB refused! Strike 1/3 
             (2 left before spectator)."
  Timeout    → strike + auto-skip: "⏱ @UserB didn't answer in 
             time. Strike 2/3 · round auto-skipped."
  3 strikes → "💥 @UserB is now a SPECTATOR for this session."
  If ALL players are spectators OR all players skipped → session
  ends: "⏹️ No active players left — session ended."

  Same prompt never repeats twice in a row (R8).

  11. SESSION FLOW (reference — how the game actually runs)
════════════════════════════════════════════════════════════════════════
  step 1 · LOBBY
      Admin: /truthordare → [🎭 Start Session]
      Bot (ephemeral): "Where should this session run?" →
      ChannelSelectMenu (defaults to current channel)
      Bot posts PUBLIC lobby embed in that channel
        (see §2) — 60s join window starts
  step 2 · ROUND START
      Join window closes → bot picks a RANDOM active player
      (never the same player twice in a row, R8-adjacent)
      Bot posts PUBLIC "Round N — @Player's turn!" embed (§3)
        with [Truth] [Dare] [Skip]
  step 3 · PROMPT
      Player presses Truth or Dare → bot posts the prompt
      embed (§4) with the timers. During the prompt, OTHER
      players' presses → ephemeral "not your turn".
      On [✅ Done] / [⏭️ Skip] / [❌ Refuse] / timeout →
      feedback post (§4 states), next round starts.
  step 4 · REPEAT
      Loop until: 3-strike spectator queue empties OR all
      players skip OR host presses [⏹️ End].
  step 5 · END
      Bot posts the Session Ended summary (§5).
      Stats + history rows written (2 transactions).
      On bot restart with 'active' session → mark 'ended'
      + summary_json {"ended_by":"bot_restart"} (no zombies).

  All timers via src/security/scheduler.js (no raw setInterval).
  All DB writes wrapped in db.transaction().

CREATE TABLE IF NOT EXISTS tod_guild_config (
  guild_id          TEXT PRIMARY KEY,
  intensity         TEXT NOT NULL DEFAULT 'pg13',
      -- 'pg' | 'pg13' | 'r'
  categories        TEXT NOT NULL DEFAULT 'Funny,Deep,Weird',
      -- CSV of enabled categories
  join_window_s     INTEGER NOT NULL DEFAULT 60,
  turn_timer_s      INTEGER NOT NULL DEFAULT 30,
  truth_timer_s     INTEGER NOT NULL DEFAULT 120,
  dare_timer_s      INTEGER NOT NULL DEFAULT 300,
  skip_tokens       INTEGER NOT NULL DEFAULT 3,
  strikes_to_kick   INTEGER NOT NULL DEFAULT 3,
  max_players       INTEGER NOT NULL DEFAULT 20,
  spicy_cooldown_until INTEGER,      -- 24h gate for Spicy pack
  created_at        INTEGER NOT NULL,
  updated_at        INTEGER NOT NULL
);

CREATE TABLE IF NOT EXISTS tod_sessions (
  id           INTEGER PRIMARY KEY AUTOINCREMENT,
  guild_id     TEXT NOT NULL,
  channel_id   TEXT NOT NULL,
  host_id      TEXT NOT NULL,
  started_at   INTEGER NOT NULL,
  ended_at     INTEGER,
  round_count  INTEGER NOT NULL DEFAULT 0,
  status       TEXT NOT NULL DEFAULT 'lobby',
      -- 'lobby' | 'active' | 'ended'
  settings_json TEXT NOT NULL, -- guild config snapshot at start
  summary_json TEXT            -- per-player stats at end
);
CREATE INDEX IF NOT EXISTS idx_tod_sessions_guild
  ON tod_sessions(guild_id, started_at DESC);

CREATE TABLE IF NOT EXISTS tod_players (
  session_id   INTEGER NOT NULL,
  user_id      TEXT NOT NULL,
  joined_at    INTEGER NOT NULL,
  turns        INTEGER NOT NULL DEFAULT 0,
  truths       INTEGER NOT NULL DEFAULT 0,
  dares        INTEGER NOT NULL DEFAULT 0,
  skips_used   INTEGER NOT NULL DEFAULT 0,
  strikes      INTEGER NOT NULL DEFAULT 0,
  status       TEXT NOT NULL DEFAULT 'active',
      -- 'active' | 'spectator' | 'left'
  PRIMARY KEY (session_id, user_id)
);

CREATE TABLE IF NOT EXISTS tod_rounds (
  id           INTEGER PRIMARY KEY AUTOINCREMENT,
  session_id   INTEGER NOT NULL,
  round_no     INTEGER NOT NULL,
  user_id      TEXT NOT NULL,
  choice       TEXT,        -- 'truth' | 'dare' | NULL (timeout)
  prompt_text  TEXT,
  category     TEXT,
  intensity    TEXT,
  result       TEXT NOT NULL,
      -- 'done' | 'skip' | 'refuse' | 'timeout'
  started_at   INTEGER NOT NULL,
  resolved_at  INTEGER
);
CREATE INDEX IF NOT EXISTS idx_tod_rounds_session
  ON tod_rounds(session_id, round_no);
